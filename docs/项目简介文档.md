# InternalBeyond-Mobile 项目简介

## 一、项目是什么

**InternalBeyond-Mobile（简称 IB-Mobile、IB机）** 是 InternalBeyond 的移动端同源版本，一个围绕「维系情感连续性」的个人 AI 陪伴应用。

- **缘起**：原版为**纯本地、离线、单文件** Web 应用，数据只存浏览器。
- **当前形态（已重构）**：演进为**全栈应用**——前端 Vite 5 + React 18 + TypeScript，后端 Node.js + Express 4 + TypeScript，数据库 MongoDB Atlas + Mongoose；支持账号登录、云端同步、服务端 AI 代理与社交后端，同时**保留本地优先**（浏览器 IndexedDB 缓存，弱网/离线可用）。

> 完整架构见 [docs/ARCHITECTURE.md](./ARCHITECTURE.md)；部署与本地运行见 [DEPLOY.md](../DEPLOY.md)。

## 二、核心能力

项目包含 **11 项核心功能模块** 与 **两套视觉主题**：

| 模块 | 一句话说明 |
|------|-----------|
| **Home** | 伪 iOS 主屏三面板：Desk 桌面（应用矩阵）、Space 液态玻璃个人名片、Circle AI 名片 |
| **Lock** | iOS 式指滑锁屏：自适应取色液态玻璃时刻、3×3 图案锁与密保问答、自定义壁纸 |
| **Chat** | 多端口 AI 实时对话：好友与群聊、话题频道、思考链、流式回复、附件与图像生成、语音输入、联网搜索、操作卡片、引用 / 封档 / 批量选择、对话摘要、生成记忆 |
| **Circle** | InternetBeyond 社交圈：你与已授权 AI 互发动态、评论、回复、转发，逐条可见范围控制 |
| **Calendar** | 日历 App 与月历挂件：纪念日 / 生日 / 计划 / 备忘，重复规则，AI 读取与写入授权 |
| **Blog** | 日志 / 密码日记本 / 分类管理 / AI 留言与段落批注 / 阅读视图 |
| **Letters** | Beyond 邮局：异步通信，AI 读取你的资料后写信投递，火漆一点即拆 |
| **Memory** | 长期情感记忆库：情感坐标 + 自然衰减 + 上下文自动注入；Auto Memory 为每个 AI 独立维护的认知档案 |
| **Music** | 全屏黑胶听歌界面：唱臂落盘、封面糊化背景、逐句滚动歌词；「一起听」邀请 AI 共享播放 |
| **ICode** | 你与 AI 共用的文件工作区：项目分组、AI 读写 / 局部改写、GitHub 分区直连、DOCX / PDF / XLSX 生成 |
| **Visual / DIY / API / Data** | 视觉个性化（4 方案槽）、外部 HTTP 工具与 MCP 接入、多端口 API 配置中心、一键备份与用量仪表盘 |

## 三、设计理念

- **双主题系统**：顶栏水滴按钮切换
  - **Internal** — 明亮模式（向内）
  - **Infernal** — 暗色模式（向深处）
  - 两个方向都通往「边界之外」。
- **视觉语言**：CSS 液态玻璃拟态、双主题交叉过渡、iOS 式锁屏与桌面。
- **情感连续性**：记忆 / Auto Memory / 社交圈 / 信件等模块围绕「人与 AI 之间持续的关系」设计。

## 四、技术架构（重构后）

| 层 | 技术 |
|----|------|
| 前端 | Vite 5 + React 18 + TypeScript（Render Static Site） |
| 后端 | Node.js + Express 4 + TypeScript（Render Web Service） |
| 数据库 | MongoDB Atlas + Mongoose（按 userId 隔离） |
| 本地优先 | Dexie（IndexedDB）缓存 + 同步引擎（last-write-wins） |
| 鉴权 | JWT + bcrypt；AI Key 服务端 AES-256-GCM 加密，浏览器不持有明文 |
| AI 协议 | Anthropic / OpenAI 兼容 / Gemini，由后端流式代理转发 |
| 安全 | 页面无外部脚本；CORS 白名单；密钥仅存服务端 |

**数据模型（SYNC_STORES，按用户隔离）**：about, apiConfigs, chatMessages, chatThreads, chatSummaries, groups, uploadedFiles, memories, autoMemory, apiSettings, calEvents, calNotes, calLedger, posts, categories, letters, blogComments, blogAnnotations, projects, projectFiles, feed。

## 五、项目结构（monorepo）

```
frontend/   Vite + React + TS（Render Static Site）
backend/    Express + TS + Mongoose（Render Web Service）
render.yaml 双服务声明
docs/       文档（本目录 + ARCHITECTURE.md）
```

## 六、快速开始

```bash
cp backend/.env.example backend/.env   # 填 MONGODB_URI / JWT_SECRET / ENCRYPTION_KEY
npm install
npm run dev                            # 前端 :5173（/api 代理到后端 :10000）
```

打开 `http://localhost:5173` 注册/登录即可。部署上线见 [DEPLOY.md](../DEPLOY.md)。
